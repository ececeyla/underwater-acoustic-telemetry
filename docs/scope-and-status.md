# System scope and test status

This project was developed during a 2026 internship at UPC/SARTI as part of a larger research effort. The repository combines surface/submerged firmware, telemetry servers and two monitoring interfaces. Modules may have been developed by different members of the team.

## Main software blocks

- **Surface firmware:** ESP32-S3, SIM7080G, GNSS, Wi-Fi, UART acoustic modem commands and sleep/wake handling.
- **Submerged firmware:** acoustic ping sequencing, addressing, retry logic and RTT data formatting.
- **Python server:** TCP JSON telemetry ingestion, node-specific logs, coordinate conversion, trilateration and visualizations.
- **Node.js dashboard:** local discovery, state polling and control requests.

## What has been checked

The repository's offline tests cover coordinate conversion, range filtering and idealized three-anchor trilateration. A separate test generates simulated logs and exercises the viewer pipeline. GitHub Actions runs the Python checks and JavaScript syntax validation.

These checks are useful for the software calculations, but they do not verify modem timing, acoustic reply success, embedded compilation or positioning accuracy in water.

## Deployment considerations

- The surface firmware needs a local `SurfaceNode/src/config.h` with addresses and network configuration.
- Node addresses vary across snapshots; check each unit's acoustic address before deployment.
- Use separate ports if both viewers need to run at the same time.
- Real telemetry logs can contain GNSS coordinates, IP addresses and other identifying information. The public demo therefore uses synthetic records.
- The local control endpoints assume a trusted network.

## Offline example

The records generated by `tools/generate_synthetic_logs.py` contain fictional positions and idealized ranges. They are intended for software testing only; they are not reconstructed results from the internship deployment.
